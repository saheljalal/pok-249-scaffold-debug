# Web App

Web App is part of Golden Path. This repository was generated from the Pokanop `sveltekit-web` template pack.

Pokanop telemetry is pre-wired through `@pokanop/telemetry`. The scoped `POKANOP_TOKEN` is stored as a repository CI secret and is never committed. Set `POKANOP_TELEMETRY=off` to disable emission.
